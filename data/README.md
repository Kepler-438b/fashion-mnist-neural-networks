# Data

Run `python download_data.py` from the repository root to download both files into this folder. They are attached to the [v1.0.0 release](https://github.com/Kepler-438b/fashion-mnist-neural-networks/releases/tag/v1.0.0).

- `train.csv`: 52,500 labelled images. Columns `pix1` … `pix1024` (pixel values 0–255 of a 32×32 grayscale image) and `label` (0–9).
- `evaluate.csv`: 17,500 unlabelled images. Columns `ID` and `pix1` … `pix1024`.

The images are a 32×32 version of [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist) by Zalando Research (MIT License), prepared for a university course.
